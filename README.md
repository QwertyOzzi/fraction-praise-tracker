# Fraction Praise Tracker — Arizona RP

Интерактивная таблица управления похвалами и отметками для фракции Arizona RP.

**🌐 Демо:** `https://ВАШ-ЮЗЕРНЕЙМ.github.io/fraction-praise-tracker/`

## Возможности

- ✅ Кнопки **[ + ]** и **[ − ]** для управления количеством
- ✅ Быстрые команды `/fractionrp` и `/praise` с автокопированием
- ✅ Система доступа по email — только авторизованные пользователи могут редактировать
- ✅ Серверная защита через Firebase Security Rules (невозможно обойти)
- ✅ Синхронизация в реальном времени между всеми пользователями
- ✅ Поиск, фильтры, экспорт данных
- ✅ Тёмная и светлая тема
